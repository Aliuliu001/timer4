# Champion Mode — Timer2 Flashcard Integration Plan

> **For Hermes:** Implement Champion mode step-by-step. Do NOT touch Timer logic.

**Goal:** Add "Champion" mode to Timer Battle where cards (image and/or text) appear in the deck area, teacher judges Correct/Wrong, mana + skills still work. Reuses image-pool + data-grid patterns from Aliuliu001/pokemon-pvp.

**Architecture:** Single `index.html` app. Champion mode lives behind a mode toggle. All Champion CSS uses `.champion-mode` prefix. Timer code untouched — guarded by `if(gameMode==='timer')` checks at entry points.

**Tech Stack:** Vanilla JS + CSS (same as Timer). No frameworks.

---

## Files

- `index.html` — ALL changes in this one file
- `assets/sfx/` — no new audio needed

## Step 1: Data Grid UI (Tab Champion)

**What:** New setup sub-tab "🃏 Champion" alongside ⏱ Time, 👹 Boss, etc.

**Content:**
- 3-column table (not 6 like pokemon-pvp):
  - Col 1: **ID Front** — number/URL, thumbnail preview on left
  - Col 2: **Text Front** — optional text (if filled, card shows text; if empty, shows image only)
  - Col 3: **Time Front(s)** — seconds to show card (empty = no timer, show until teacher clicks)
- "Add 10 Rows" button
- Auto-fill tool: select column (1/2/3), From/To numbers → fills sequentially
- Quick Fill Time: input seconds + "Fill Time" button → fills Time Front column
- Clear: Clear All / Clear Col 1 / Clear Col 2 / Clear Col 3
- Upload Files / Upload Folder / Clear Pool (image storage)
- Paste support: paste tab-separated Excel data directly into grid
- Cards per round: number input (default 3, range 2–7)
- Display mode: Image only / Text only / Image + Text (radio)
- Text size: slider or dropdown (small/medium/large)

**Key code to reuse from pokemon-pvp:**
- `addGridRow()` — simplified to 3 columns
- `paste` event on tbody — same tab-separator logic
- `autoSaveTableData()` — debounced localStorage save
- `buildDeck()` — shuffle cards from grid data
- Image upload → IndexedDB + WebP compression (same `handleImageUpload` pattern)
- Auto-fill sequential numbers (same `btn-auto-fill` logic)

**Storage keys (Champion-specific):**
- `champion_data` — array of `{id, text, time}`
- `champion_cards_per_round` — number
- `champion_display_mode` — 'image' | 'text' | 'both'
- `champion_text_size` — 'sm' | 'md' | 'lg'
- `champion_image_pool` — IndexedDB 'ChampionImagePool' store

## Step 2: Mode Toggle

**What:** At the top of screen-setup, before Start button, add two mode buttons:

```
[⏱ Timer] [🃏 Champion]
```

- Defaults to Timer
- Selecting Champion shows Tab Champion, hides irrelevant Timer tabs (BG/Music stays)
- Selecting Timer shows all original tabs
- Stored in localStorage: `game_mode`
- When Champion is active, `btn-start` calls `startChampion()` instead of `startArena()`

## Step 4: Card Rendering

**What:** Show cards one round at a time (cards_per_round cards visible).

**Card display logic (per DISPLAY_MODE):**
- `image`: show image from pool by ID, full card
- `text`: show text, large font, centered
- `both`: image on top 60%, text on bottom 40%

**Card timer:**
- If Time Front is set → countdown shown on card badge
- When timer expires → card auto-marks as time-up (no mana gained)
- If Time Front empty → card stays until teacher clicks Correct/Wrong

**Card size:** responsive to remaining arena height, max 280px wide.

**After all cards judged → next round:** draw next N cards from deck. When deck empty → reshuffle all cards.

---

## Step 5: Correct/Wrong in Champion Mode

**What:** Each card has its own Correct/Wrong state.

- Teacher clicks Correct on a card → card gets ✅ overlay, +1 mana
- Teacher clicks Wrong on a card → card gets ❌ overlay, mana unchanged, combo reset
- When all cards in current round are judged → auto-draw next round
- Skills still cost mana, food still throws at Boss
- Boss walks forward like Timer (progress = cards judged correctly / total)

---

## Step 6: Boss Integration

**What:** Boss still walks across arena in Champion mode.

- Boss progress = (correct cards / total cards) * 100
- Boss speed: walks slower than Timer (adjustable in settings)
- Food/skills still work the same way (throw at Boss, eating, etc.)
- When all cards are done and Boss hasn't reached end → Win
- If Boss reaches end → Lose

## Step 7: Champion Settings Tab

**What:** Dedicated settings pane in Tab Champion for Champion-specific options:

- Cards per round: 2/3/4/5/6/7
- Display mode: Image / Text / Both
- Text size: Small / Medium / Large
- Boss walk speed: slider (slow/medium/fast)
- Time per card: default (if not set per card)

## Step 8: Guard Timer Code

**What:** Ensure Timer mode is completely unaffected.

**Approach:**
- All Champion functions are prefixed `champ*` (e.g., `champStart`, `champDraw`, `champJudge`)
- Timer entry points check `if(gameMode!=='timer') return;`
- CSS for Champion uses `.champion-mode` prefix on all new selectors
- No existing CSS/JS modified except: body class toggling, mode button, btn-start click handler

## Risks

- **Timer regression:** biggest risk. Every Timer function must be guarded. Mitigation: Step 8 guards FIRST.
- **IndexedDB quota:** image storage. Same pattern as pokemon-pvp (WebP compression, 5MB warning).
- **Card sizing on 14":** must fit in arena alongside Boss/Hero. Use % sizing, not px.
- **Paste compatibility:** Excel paste with tabs works the same way as pokemon-pvp.
